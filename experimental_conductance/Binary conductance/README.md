# Binary experimental program result

For binary encoding, `0` is set to 0 uS, and `1` is set to 150 uS. The ideal pattern is in "ideal_target" file; and program results are in "program_result" file. 

To be more specific, "cov_binary_ref_target1.npy" is the ideal pattern, and "20240820_cov_cam1.npy" is the experimental programming result from real memristor macro.
